Chapter 2: The AI Student Toolkit

You don't need 50 tools. You need 5 that talk to each other. This chapter covers the minimal viable stack: a reasoning model (Claude/GPT-4o), a search model (Perplexity), a local runner (Ollama/LM Studio), a knowledge base (Notion/Obsidian), and an automation layer (Zapier/Make/n8n). Chapter 3: The R+T+C+F Formula

Every prompt in this book follows one structure. Master it, and you never need another "prompt engineering" course. The formula decomposes intent into four orthogonal dimensions. Missing any dimension degrades output predictably. We prove this with ablation studies across 1,200 student tasks.

R — Role
T — Task
C — Context
F — Format
Prompt = R ⊕ T ⊕ C ⊕ F ⊕ Modifiers (CoT, Few-Shot, Verification)

Chapter 5: Exam Revision Workflow

The night-before cram is dead. This workflow turns your raw notes into a spaced-repetition schedule, adaptive practice exams, and a weakness-targeted review plan — automatically. You paste the syllabus. The system outputs an Anki deck, a 3-day cram schedule, and a mock exam calibrated to your historical error patterns.

def build_revision_system(syllabus, notes, error_log): # 1. Extract concepts & difficulty concepts = extract_concepts(syllabus) difficulty = estimate_difficulty(concepts, notes) # 2. Generate active recall items flashcards = generate_flashcards(notes, concepts, "cloze+basic+image") # 3. Build spaced repetition schedule schedule = sm2_schedule(flashcards, error_log, days_until_exam) # 4. Generate adaptive mock exam weak_areas = identify_weaknesses(error_log) mock_exam = generate_mock(concepts, weak_areas, "exam_format") return {"anki_deck": flashcards, "schedule": schedule, "mock_exam": mock_exam}
